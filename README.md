# Sophia Salas | Prelims + Midterms 2026

Static website ready for GitHub and Cloudflare Pages.

1. Unzip this package.
2. Upload index.html, styles.css, script.js, favicon.svg, _headers and the assets folder to your existing repository. Keep the folder structure. Upload the extracted contents, not the ZIP itself.
3. For Cloudflare Pages use no build command and the repository root as output. For GitHub Pages publish the repository root.

The current Prelims and Midterms collections are included. Midterms opens by default; ?term=prelims opens Prelims.
